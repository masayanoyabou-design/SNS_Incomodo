# Product Requirements Document (PRD): Incomodo (インコモード)

## 1. 概要 (Overview)
- **プロダクト名**: Incomodo（インコモード / 由来：不便な、面倒な）
- **コンセプト**: 「行かなきゃ、読めない。」あえて不便さを楽しむ、位置情報連動型スローコミュニケーションSNS。
- **ターゲット層**: 
  - 常時接続や即レス文化、SNS疲れを感じている20〜30代
  - 大切な人（家族・パートナー・親友）と深い繋がりを持ちたい人
  - 手紙やフィルムカメラなどのアナログカルチャーを好む層

## 2. コア機能要件 (Core Features)

### F-01: ポスト（受け取り場所）設定
- ユーザーは最大4箇所（自宅1箇所 ＋ 任意の拠点3箇所）を「手紙の受け取り場所（ポスト）」として登録可能。
- **チート防止（工事期間）**: ポストの新規追加・変更後は「ポスト設置工事中」となり、有効化まで48時間の待機時間が発生する。
- **開封判定**: 登録されたポストの座標から半径50m以内に入った場合のみ、該当の手紙を開封・閲覧可能。

### F-02: 非同期・通知なしの手紙体験
- **プッシュ通知の完全排除**: メッセージが届いてもアプリ側から通知は行わない（ユーザーが自らポストに足を運んで確認する）。
- **送信フロー**: 送り手は相手のポスト位置を知る必要はなく、「〇〇さん宛て」で送信可能（システムが相手のポストに自動配送）。
- **既読・ステータス**: 送信時は「配送完了」、相手が現地で開封したタイミングで「受取完了」のステータスに変化。

### F-03: 手紙コンテンツ（声の手紙・写真）
- **テキスト**: メッセージの送受信。
- **ボイスメッセージ（強制秒数縛り）**:
  - 下限（最低秒数）: 15秒（短文の作業的返信を排除し、語りを促す）
  - 上限（最大秒数）: 3分（長時間の拘束を防ぎ、濃密な内容にする）
- **写真同封**: 1通につき数枚の写真を同封可能。
- **コレクション機能**: 開封した手紙は、クラフト紙風のアルバム内に消印（開封日・場所）付きで永続保存される。

### F-04: ランダムポスト（見知らぬ人との文通）
- 週末やイベント時に、特定の公共スポット（公園等）に「宛先のない手紙（漂流郵便）」がランダム配置される。
- 散歩や外出の動機付けおよび初期の過疎対策として機能。

### F-05: 切手システム（マネタイズ基盤）
- 手紙の送信には「切手」を消費。
- 毎日1〜2枚の通常切手を無料配布（送信数に自然な制約をかける）。
- 追加切手や特別デザイン切手（記念消印・速達風など）を有料アイテムとして販売。

## 3. UI/UXデザイン要件 (Design Principles)
- **トーン＆マナー**: クラフト紙、素朴な温もり、アナログ感、落ち着いた余白。
- **カラーパレット**: エクリュ（生成色）、クラフトブラウン、セピア、アンティークゴールド。
- **タイポグラフィ**: 明朝体、レトロなセリフ体、タイプライター風フォント。
- **サウンドデザイン**: 紙が擦れる音、ポストが開く音など（将来実装）。
